# Lister

> **Lister** — мінімалістичний та швидкий веб-додаток для створення ієрархічних списків із динамічним підрахунком цін і часу, збереженням у браузері та підтримкою імпорту/експорту JSON.

Побудований на чистому **HTML5**, **CSS3** та сучасному **JavaScript (ES6+ модулі)** без використання сторонніх фреймворків чи зовнішніх бібліотек.

---

## ✨ Основні можливості

- **Текстоподібний мінімалістичний інтерфейс**:
  - Відсутні громіздкі рамки навколо полів вводу.
  - Редаговані поля мають лаконічне підкреслення, яке підсвічується акцентним кольором при фокусі.
  - Легкі текстові кнопки дій (`+ рядок`, `+ підсписок`, `+ список`, `×`).
  - Фірмова палітра кольорів:
    - Фон: `#E7E7E6`
    - Текст та підкреслення: `#465362`
    - Акценти: `#C57B57`

- **Ієрархічна структура та необмежена вкладеність**:
  - До кожного елемента списку можна додати довільну кількість вкладених списків.
  - Зміст батьківського елемента автоматично стає назвою вкладеного підсписку.

- **Автоматичний підрахунок цін та часу**:
  - Якщо елемент має вкладені списки, його власні значення ціни та часу автоматично обчислюються як сума всіх вкладених елементів (поля блокуються для ручного вводу та позначаються пунктирним підкресленням).
  - У заголовку кожного списку (як основного, так і вкладених) динамічно відображаються агреговані показники: **Разом ціна** та **Разом час**.

- **Керування багатьма списками**:
  - Зручна панель вкладок у верхній частині екрана.
  - Додавання нових списків (`+ список`).
  - Редагування назви активного списку прямо у заголовку.
  - Безпечне видалення списків з підтвердженням.

- **Клавіатурні скорочення (швидке введення)**:
  - <kbd>Enter</kbd> у полі змісту — створити новий елемент поточного списку відразу після поточного.
  - <kbd>Ctrl+Enter</kbd> (або <kbd>Cmd+Enter</kbd> на Mac) — створити новий вкладений підсписок або елемент.
  - Автофокус: при першому запуску курсор автоматично встановлюється у поле «зміст» першого елемента.

- **Збереження даних та резервні копії**:
  - Усі дані автоматично синхронізуються з `localStorage` браузера при кожному введенні.
  - **Експорт**: збереження активного списку у файл `.json`.
  - **Імпорт**: завантаження списку з файлу `.json` (додається як новий список поруч із наявними).

- **Адаптивність (Mobile-First)**:
  - Інтерфейс оптимізовано як для десктопних моніторів, так і для планшетів та смартфонів.

## 🚀 Запуск проекту локально

Оскільки проект використовує нативні ES-модулі (`<script type="module">`), його рекомендується відкривати через локальний HTTP-сервер.

### Варіант 1: Python (вбудований)
```bash
python3 -m http.server 4321
```
Після цього відкрийте у браузері: [http://localhost:4321](http://localhost:4321)

### Варіант 2: Node.js (npx serve)
```bash
npx serve .
```

## 📁 Структура проекту

```
lister/
├── index.html              # Головна HTML5 сторінка (семантична розмітка)
├── project.md              # Початкова специфікація та вимоги проекту
├── README.md               # Документація проекту
├── styles/
│   ├── variables.css       # Дизайн-токени (кольори, шрифти, відступи)
│   ├── reset.css           # Базове скидання стилів браузера
│   ├── layout.css          # Мобільний адаптивний лейаут та підвал
│   └── components.css      # BEM-стилі для полів, кнопок, вкладок і сум
├── src/
│   ├── app.js              # Точка входу, координація подій, гарячі клавіші
│   ├── state.js            # Реактивний менеджер стану списків та елементів
│   ├── storage.js          # Збереження в localStorage, імпорт/експорт JSON
│   ├── calculations.js     # Рекурсивні алгоритми підрахунку цін та часу
│   ├── render.js           # Рендеринг DOM-дерева, фокус і оновлення сум
│   └── utils.js            # Допоміжні функції (id, форматування, debounce)
└── tests/
    ├── test_core.js        # Модульні тести розрахунків і санітизації імпорту
    └── test_app_flow.js    # Інтеграційні тести повного життєвого циклу стану
```

## 📋 Формат даних JSON (Експорт / Імпорт)

Експортований файл має просту та зрозумілу JSON-структуру:

```json
{
  "id": "list-uuid",
  "title": "Мій список",
  "items": [
    {
      "id": "item-1",
      "content": "Батьківський пункт",
      "price": 0,
      "time": 0,
      "nestedLists": [
        {
          "id": "sublist-1",
          "title": "Батьківський пункт",
          "items": [
            {
              "id": "nested-item-1",
              "content": "Вкладене завдання",
              "price": 150,
              "time": 2,
              "nestedLists": []
            }
          ]
        }
      ]
    }
  ]
}
```
